The v0.1 evidence vocabulary is an experimental interchange contract, not a new solar lifecycle standard or certification. Existing system data should map into it without replacing the producer's internal records.

| Candidate standard/context from the supplied specification | Intended mapping surface | Verified implementation status |
| --- | --- | --- |
| SunSpec / Orange Button | Asset, installation, system configuration | No field-level mapping verified yet |
| UNTP DPP / Digital Traceability Events | Actors, provenance, service/replacement events | No export/conformance claim |
| IEC 62446 family | Commissioning/inspection evidence and measurements | No normative requirement encoded |
| REA / NEMSA | Nigerian installation and actor authorization context | No regulatory compliance claim |

These are mapping work items inherited from the research brief. Before any adapter or conformance claim, verify the applicable primary specification/version, record exact source fields and identifiers, and test both preserved meaning and unsupported concepts. No manufacturer policy or regulatory requirement may be inferred from this table.
